# Emerald Browser v2.0.0 — Marble Edition

Emerald's first full design refresh. From an experimental scaffold to a cohesive, responsive browser *interface prototype*.

### What's new
- Marble-first visual system: honed white stone, emerald and forest accents, sculptural pearl illustration, editorial typography, and open whitespace.
- New pearl-in-stone favicon, lightweight SVG artwork, no external font or UI-library downloads.
- Responsive navigation for desktop, tablets, and phones, with bottom-accessible command dock.
- Real interactive **Missions**, with create/archive/restore controls saved locally.
- Editable bookmarked **Places** in a new library, saved in localStorage.
- Command search via ⌘K/Ctrl+K or /; local match suggestions; URL/search submission opens a new browser tab.
- Accessible dialogs, visible focus treatment, reduced-motion support, optional Basalt theme.
- Truthful standalone **Downloads** placeholder (no fabricated download state).
- Dedicated JavaScript navigation normalization tests + GitHub Actions CI.
- Updated README and version history.

### Important
**This is a browser interface prototype hosted on GitHub Pages.** It does not ship a native browser engine, history capture, an AI runtime, tracking prevention, a validated security layer, extension support, device revival, or actual download management. Opened websites use your existing browser, and saved demo data stays in the current browser's localStorage.
