ABOUT THE EDITION

Made of marble, not glass.

Emerald v2.0.0 is an experimental browser interface built with plain HTML, CSS, and JavaScript. The launcher, missions, and bookmarks are interactive demo features saved in your own browser. This is not yet a standalone browser, security layer, or AI assistant.
